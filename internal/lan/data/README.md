Offline MAC-assignment vendor data derived from the public IEEE MA-L, MA-M, MA-S and IAB listings in the installed Debian/Ubuntu ieee-data package. IEEE does not assert copyright in these public listings or restrict their redistribution. Local/private MAC addresses are deliberately not attributed to an IEEE vendor. Vendor ownership identifies the network adapter assignment, not necessarily the complete device manufacturer.

Source: https://standards.ieee.org/products-programs/regauth/
Only assignment prefixes and organization names are included; postal addresses are omitted.
